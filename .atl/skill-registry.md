# Skill Registry

This project uses the Spec-Driven Development (SDD) OpenSpec setup.

- `sdd-init`: Initialize SDD project configuration and structure.
- `sdd-explore`: Initial exploration for changes.
- `sdd-propose`: Propose architectural or feature changes.
- `sdd-spec`: Write detailed delta specifications for changes.
- `sdd-design`: Document implementation design and architecture.
- `sdd-tasks`: Generate task list based on design.
- `sdd-apply`: Implement the tasks in code.
- `sdd-verify`: Verify the implementation against specs.
- `sdd-archive`: Archive completed changes and merge specs.
